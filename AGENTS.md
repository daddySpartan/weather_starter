# AGENTS

This repository is a full-stack TypeScript weather app starter with a Node/Express backend, React/Vite frontend, and SQLite via Drizzle.

## Essentials For Every Task

- Build all packages: npm run build
- On Windows, prefer npm exec vitest run because root npm test uses POSIX-style env assignment.
